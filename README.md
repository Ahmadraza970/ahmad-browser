## ✨ Features

- **Nothing survives closing** — no history, no cookies trail, no session restore. Close it and it's gone.
- **Tracker blocking built in** — a blocklist stops known tracking domains before they load.
- **Search your way** — Google search built in, with Bing and Brave as fallbacks.
- **Home tiles** — one-tap shortcuts to the sites that matter.
- **Real tabs** — open, switch and close tabs like a normal browser.
- **Friendly error pages** — when a page fails, you get plain language and a Retry button, not a cryptic code.

## 🔒 Honest limits

Ahmad Browser is a privacy-hygiene browser, **not a VPN** and not an anonymity tool. Your network provider can still see which domains you connect to. What it does guarantee: the browser itself keeps nothing about where you've been once you close it.

Full details: [Privacy page](https://ahmad-browser.vercel.app/privacy.html)

## 🛠️ Tech

- Kotlin + Android WebView
- Tracker blocklist filtering at request level
- No analytics, no accounts, no data collection
